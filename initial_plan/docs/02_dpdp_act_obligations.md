# DPDP Act 2023 Statutory Obligations

## Core Privacy Principles
1. Purpose Limitation (Section 4)
2. Data Minimisation (Section 6)
3. Storage Limitation (Section 8(7))
4. Accuracy & Completeness (Section 8(3))
5. Security Safeguards (Section 8(5))


## Section 8: General Obligations of Data Fiduciary
- Section 8(1): Responsibility remains with Fiduciary even if a Data Processor is engaged.
- Section 8(2): Processing under valid contract with Data Processors.
- Section 8(4): Duty to inform Data Principals upon significant modifications.
- Section 8(6): Mandatory reporting of personal data breach.
- Section 8(9): Establish grievance redressal mechanisms with local contact points.
